# AI-Security-Engineer-Projects

A collection of hands-on **AI Security Engineering projects** focused on understanding, attacking, securing, and building AI-powered applications. These projects explore practical security challenges in Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), prompt injection, and AI.

## Projects

| # | Project | Focus | Status |
|---|---|---|---|
| 1 | [AI Red Team Lab](https://github.com/OmDorugade/AI-Security-Engineer-Projects/tree/main/01.AI_Red_Team_Lab) | Testing LLM vulnerabilities, prompt injection, information disclosure, and excessive agency | Completed |
| 2 | [SecureRAG](https://github.com/OmDorugade/AI-Security-Engineer-Projects/tree/main/02.SecureRAG) | Securing RAG applications through retrieval validation, document trust boundaries, and prompt injection detection | Completed |

## Technologies & Tools

- **Languages:** Python
- **AI/LLM:** Ollama, Llama 3.1
- **Frameworks:** Streamlit, LangChain
- **Vector Database:** ChromaDB
- **Database:** SQLite
- **Security:** Prompt Injection Detection, RAG Security, LLM Vulnerability Testing, Agent Security

## Learning Objectives

- Understand LLM architecture, vulnerabilities, and attack surfaces.
- Perform practical AI red teaming and security testing.
- Implement security mechanisms for RAG-based applications.
- Explore Agentic AI architectures and Model Context Protocol (MCP).
- Apply AI security concepts through practical projects and demonstrations.

## Safety & Testing

All security testing is performed in controlled environments using locally hosted models, fictional scenarios, and test data. Projects are intended for educational purposes and authorized security research.

## Approach

**Build → Attack → Analyze → Secure → Retest**

Each project focuses on practical implementation, understanding security weaknesses, applying defensive techniques, and documenting the results.
